สร้างภาพห้องสตูดิโอทำงานแบบ Isometric 3D Cutaway Diorama สำหรับสตูดิโอขนาดเล็กที่ทำงานเพียงคนเดียว ชื่อ “[ชื่อ STUDIO]” เจ้าของสตูดิโอทำงานเกี่ยวกับ “[อาชีพ / ประเภทงาน]”

ออกแบบให้เป็นห้องทำงานส่วนตัวขนาดเล็ก กะทัดรัด ใช้งานได้จริง และสะท้อนตัวตนของเจ้าของห้อง ใช้โทนสีหลัก “[สีหลัก]” และ “[สีรอง]” พร้อมสี Accent “[สี Accent]” เล็กน้อย เพื่อสร้างเอกลักษณ์ให้กับ Studio

ห้องมีขนาดประมาณ “[ขนาดห้อง เช่น 3.5 x 3.5 เมตร]” ใช้แปลนห้องทรงสี่เหลี่ยมเรียบง่าย สัดส่วนสมจริง ไม่อัดแน่นจนเกินไป และมีพื้นที่ว่างเพียงพอให้มองเห็น Layout และตำแหน่งของเฟอร์นิเจอร์แต่ละชิ้นได้อย่างชัดเจน

แสดงห้องทั้งหมดจากมุมกล้องสูงแบบ 3/4 Isometric ใช้ Orthographic Projection ลักษณะเหมือน Architectural Dollhouse หรือห้องจำลองขนาดเล็ก โดยเปิดผนังออก 2 ด้าน เพื่อให้มองเห็นพื้น ผนัง การจัดวางเฟอร์นิเจอร์ และองค์ประกอบทั้งหมดภายในห้องอย่างชัดเจน เหมาะสำหรับนำภาพไปใช้เป็น Reference สำหรับสร้างโมเดลใน Blender

พื้นที่ทำงานหลักประกอบด้วยโต๊ะ “[รูปแบบ / สีของโต๊ะ]” จำนวน 1 ตัว เก้าอี้ทำงาน “[รูปแบบ / สีของเก้าอี้]” จำนวน 1 ตัว หน้าจอคอมพิวเตอร์ “[จำนวนจอ]” จอ ใช้คอมพิวเตอร์ประเภท “[ประเภทคอมพิวเตอร์ เช่น PC / Mac / Laptop]” พร้อมคีย์บอร์ด เมาส์ โคมไฟตั้งโต๊ะ โทรศัพท์มือถือ “[ของส่วนตัวบนโต๊ะ]” และจัดสายไฟให้เรียบร้อย

บนผนังหลักของห้องติดชื่อหรือโลโก้ “[ชื่อ STUDIO]” ในรูปแบบ “[สไตล์โลโก้]” ใช้ “[วัสดุ / รูปแบบแสงของโลโก้]” ทำให้ชื่อ Studio มองเห็นได้ชัดเจน แต่ยังคงความเรียบง่าย ทันสมัย และสามารถนำไปสร้างเป็นโมเดล 3D ได้ง่าย

เพิ่มรายละเอียดเล็ก ๆ ที่สะท้อนตัวตน งาน และความสนใจของเจ้าของ Studio เช่น “[ของตกแต่ง 1]”, “[ของตกแต่ง 2]”, “[ของตกแต่ง 3]”, “[ของตกแต่ง 4]” และ “[ของตกแต่ง 5]” โดยเลือกเฉพาะสิ่งที่จำเป็น ไม่ทำให้ห้องรกหรือมีรายละเอียดมากจนเกินไป

องค์ประกอบภายในห้องประกอบด้วยพื้น “[วัสดุพื้น]” ผนัง “[รูปแบบ / สีผนัง]” หน้าต่าง “[รูปแบบหน้าต่าง]” ชั้นวางหรือพื้นที่เก็บของ “[รูปแบบชั้นวาง / ตู้]” ระบบไฟ “[รูปแบบแสง]” และ “[ต้นไม้ / ของตกแต่งเพิ่มเติม]” จำนวนเล็กน้อย

ใช้สัดส่วนเฟอร์นิเจอร์และวัตถุที่สมจริง วัตถุแต่ละชิ้นต้องแยกออกจากกันอย่างชัดเจน มีรูปทรงที่เข้าใจง่าย และสามารถนำไปสร้างเป็นโมเดล 3D ใน Blender ได้จริง

สไตล์ภาพเป็น Stylized Isometric 3D Render คุณภาพสูง เน้นรูปทรงเรขาคณิตที่เรียบง่าย ขอบวัตถุมี Soft Rounded Bevel เล็กน้อย รูปทรงสะอาด เหมาะกับการทำโมเดล 3D ใช้วัสดุหลัก ได้แก่ “[วัสดุหลัก 1]”, “[วัสดุหลัก 2]”, “[วัสดุหลัก 3]” และ “[วัสดุหลัก 4]”

ใช้วัสดุแบบ Matte และพื้นผิวที่เรียบง่าย ไม่เน้น Texture ที่ซับซ้อน มี Ambient Occlusion, Soft Global Illumination และเงาที่นุ่ม ใช้แสงที่สว่าง สะอาด และช่วยให้สามารถอ่านรูปทรงของวัตถุทุกชิ้นได้อย่างชัดเจน

ภาพโดยรวมให้ความรู้สึกเหมือน Miniature Workspace Diorama ระดับพรีเมียม เป็นห้องทำงานขนาดเล็กที่อบอุ่น ทันสมัย เป็นมืออาชีพ มีเอกลักษณ์ และเห็นได้ชัดว่าเป็นพื้นที่ทำงานที่ออกแบบมาสำหรับเจ้าของเพียงคนเดียว

ให้ความสำคัญกับความชัดเจนของ Geometry, สัดส่วนที่สมจริง, Layout ที่อ่านง่าย และรูปทรงที่สามารถนำไปสร้างเป็นโมเดล 3D ได้ มากกว่าความซับซ้อนทางศิลปะ วัตถุสำคัญทุกชิ้นต้องมี Silhouette และโครงสร้างที่ชัดเจน

หลีกเลี่ยงคน, โต๊ะทำงานหลายชุด, ออฟฟิศขนาดใหญ่, Open-plan Office, วัตถุจำนวนมากเกินไป, ห้องรก, วัตถุลอย, Geometry ที่เป็นไปไม่ได้, เฟอร์นิเจอร์ผิดสัดส่วน, Perspective ที่บิดเบี้ยว, Fisheye Lens, Texture ที่ซับซ้อนเกินไป, RGB Lighting ที่มากเกินไป, Cyberpunk, Sci-fi และอุปกรณ์ที่ดูเหนือจริง

ภายในภาพอนุญาตให้มีข้อความที่อ่านได้เฉพาะชื่อ “[ชื่อ STUDIO]” เท่านั้น

แสดงห้องทั้งหมดภายในภาพ ใช้มุมมอง Isometric ที่สม่ำเสมอ, Orthographic Camera, องค์ประกอบภาพแบบ Architectural Visualization และออกแบบทุกอย่างให้เหมาะสำหรับใช้เป็น Blender 3D Modeling Reference
